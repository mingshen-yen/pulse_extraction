Near-fault velocity-pulse extraction

Python port of the Shahi & Baker stratified-wavelet pulse classifier, fed by near-real-time strong-motion waveforms: fetch → baseline correction → Arias window → classifier. Each event below is pulled from a strong-motion archive (GeoNet FDSN, ESM), processed end-to-end, and mapped.

Reproduces the Shahi & Baker (2014) pulse table to 25 / 27 records across 5 events (median |ΔTp| 0.03 s). source & validation →
