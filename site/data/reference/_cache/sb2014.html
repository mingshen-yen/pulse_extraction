November 1st, 2012 Pulse Classifications from NGA West2 database

by Shrey Shahi and Jack Baker

Below is a table of the ground motions currently identified as pulse-like in the NGA-West2 database. You can click on the hyperlinks in the far-right column to see relevant maps, time histories and other supporting documentation for each ground motion. This is a first-draft release, and we are currently working on documentation for these results and improvements to the presentation of this material.

Notes:

  • These results were produced using the classification scheme described on this web page.
  • These results were computed November 1st, 2012. We will keep a date tag on this page and announce updates to the results.
  • These results are based on the June 2012 version of the NGA-West2 database.
  • The raw time history data of the extracted pulses is not yet available. PEER will make the data available to the general public at some point in the future.
  • If you have any observations, comments or requests regarding the general format or specific results from these classifications, please e-mail Jack Baker and Shrey Shahi.

Table explanation:

  • Columns 1 through 7 correspond to fields in the NGA West 2 flatfile, and are simply repeated here to aid in interpreting the results.
  • Tp is the period of the extracted pulse in the direction of the strongest observed pulse.
  • PGV is the peak ground velocity of the original ground motion in the direction of the strongest observed pulse.
  • Orientation (w.r.t. North) is the orientation of the strongest observed pulse, in degrees clockwise from North. For cases where the as-recorded orientation is not available, this field takes value -999.
  • Orientation (w.r.t. Fault Parallel) is the smallest angle in degrees between the local fault parallel orientation and the orientation of the strongest observed pulse. For cases where the as-recorded orientation or fault orientation is not available, this field takes value -999.
  • Fault Normal Pulse indicates whether the ground motion in the fault normal direction is classified as pulse-like. This field takes a value of 1 if the fault-normal motion is pulse-like, 0 if it is not pulse-like, and -999 if the as-recorded orientation or fault orientation is not available (and thus the fault-normal direction could not be determined).
  • Directivity Effect Indicates if the authors believe if the pulse was caused due to directivity effect (1) or due to some other cause (0). For comments explaining some classifications see the summary pages
  • Summary Page URL Provides a link to a web page providing additional maps, time histories and other supporting documentation for each ground motion.
